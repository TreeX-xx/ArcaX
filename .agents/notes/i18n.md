# Internationalization

## Scope

Minimal English/Chinese switching implemented through `xdo` on 2026-10-28. It covers frontend-owned interface text, the language control and persistence. Backend-originated messages remain English (see gaps).

## Design

No translation dependency was added. English source text is the message ID, which keeps the catalog readable and makes an untranslated message fall back to the original text.

- `src/lib/i18n.ts` — `translate(language, message, vars)`, `useI18n()` for components and `tGlobal()` for stores, callbacks and non-React modules.
- `src/lib/i18n.zh.ts` — `ZH_MESSAGES`, a flat `Record<string, string>` keyed by English source text.
- `src/store/settingsStore.ts` — new persisted `language: 'en' | 'zh'`, default detected from `navigator.language` (`zh*` → Chinese) and overridden by persisted state.
- `src/components/layout/AppShell.tsx` — keeps `document.documentElement.lang` in sync (`zh-CN` or `en`).
- `src/app/settings/page.tsx` — Language selector under Appearance.
- `src/components/layout/TopBar.tsx` — translate button toggles languages.

Message interpolation uses named placeholders: `t('{count} files', { count })`. A translation must preserve every placeholder; values without a catalog entry render in English.

Tab titles, navigation labels and ACL/expiry option labels are stored as canonical English values and translated at render time, so persisted tabs continue to work across language changes.

## Second pass

The follow-up pass closes the most visible bilingual gaps:

- Backend enum values are translated at display time: job statuses (`Preparing`, `Running`, `Interrupted`, `Missed`), sync-preview actions (`New`, `Changed`, `Unverified`, `Unchanged`, `Filtered`, `Skipped`), transfer phases (`Fetching source`, `Retrying source`, `Uploading to S3`), credential types, bucket versioning states and ACL permissions/grantee types. Unknown values fall back to the backend text.
- Dates and times use the selected locale (`zh-CN` / `en-US`) through `localeFor()`, exposed by `useI18n()`. This covers transfer pages, jobs, recent items, bucket creation dates, presigned expiry, version history, properties and the settings log.
- Remaining frontend-owned messages were moved into the catalog: preview-navigation failures, listing-cursor errors, public-URL access results and saved-job notifications.
- Backend job messages now say ArcaX instead of the upstream project name.
- The NSIS installer offers English and Simplified Chinese (`SimpChinese`) with a language selector.

## Known gaps

- Rust `AppError` variants and dynamically composed backend error strings remain English; only known enum values and exact messages are mapped.
- A few technical values stay untranslated by design: storage class names, region codes, version IDs, content types and file extensions.
- Some backend-generated run messages and transfer failure details may remain English when they are not in the catalog.
- The initial static `lang` attribute is `en` until the client mounts.
